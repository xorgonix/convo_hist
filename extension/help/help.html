The idea

Every ChatGPT thread you download becomes a JSON file in your Library folder — the source of truth. Exporting turns those files into markdown in your Vault folder (Obsidian-ready, with frontmatter). A line in the panel means the file exists on disk — nothing else is listed.

First-time setup

  • Open ⚙ Settings in the panel header.
  • Library — choose the folder where downloaded JSONs live (e.g. F:\chatgpt_threads).
  • Vault — choose the folder for markdown exports.
  • Test writes a marker file (_convo_hist_here.txt) into each folder — check it in Explorer to confirm the exact location. The browser cannot show full paths; this is how you verify.

Panel buttons

DownloadCrawl ChatGPT's list and download new + changed threads into the library. Auto-runs when the panel opens. Paced, self-throttling on rate limits, resumable — a paused run continues where it stopped.
ExportWrite markdown for the selected threads (or all, if none selected) into the Vault. Before writing, each thread is compared with ChatGPT's live list and refreshed if stale. Pure local file writes.
DigestAdd a summary + tags to every thread that lacks them, into the library JSON. Run Export afterwards to refresh the vault markdown.
↻Re-read the library folder — picks up files you added or moved manually.

Row actions

  • Click a row — select it for export. Select all — the checkbox at the top. Double-click a row — export just that thread.
  • 📄J — copy the thread's JSON to the clipboard.
  • 📄M — copy freshly-rendered markdown to the clipboard.

Search

Searches inside downloaded threads. Try: hydration (fuzzy), code: (threads with code blocks), user: topic (your messages only), assistant: topic (replies only). Result cards show tag chips (after Digest) and an Open in ChatGPT ↗ deep link.

Where everything lives

Library folderthreads/<Title> (<id>).json — the source of truth

BrowserTiny caches only (list, settings) — no thread data

Re-download is always possible while threads exist in your ChatGPT account — deleting the library is recoverable.
