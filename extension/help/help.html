The idea

Import reads conversation metadata and bodies from ChatGPT and writes one JSON file per thread into the Conversarium — the folder holding your canonical thread JSON. Browse/Search reads the files that actually exist there. Digest adds local summaries and tags to those files. Export converts Conversarium JSON into markdown in your vault — Export is local and makes no ChatGPT requests. A line in the panel means the file exists on disk — nothing else is listed.

First-time setup

  • Open ⚙ Settings in the panel header.
  • Conversarium — choose the folder where imported thread JSONs live (e.g. F:\chatgpt_threads).
  • Vault — choose the folder for markdown exports.
  • Verify writes a marker file (_thread_o_matic_here.txt) into each folder — check it in Explorer to confirm the exact location. The browser cannot show full paths; this is how you verify.
  • Change folder… always opens the picker, even when a folder is already set. Reconnect restores access after the browser drops it. Forget removes only the saved handle — it never deletes files.

Panel buttons

ImportRead ChatGPT and save new or changed threads as JSON in the Conversarium. Runs only when you press it. Paced, self-throttling on rate limits, resumable — a paused run continues where it stopped.
ExportConvert the selected Conversarium threads (or all, if none are selected) to the configured output folders. Export renders exactly what is currently in the Conversarium — run Import first to pull the newest ChatGPT content. No ChatGPT access happens during Export.
DigestAdd a local summary + tags to every thread that lacks them, into the Conversarium JSON. Run Export afterwards to refresh the vault markdown. Optional local AI backends (Ollama, LM Studio) are contacted on localhost only when configured.
↻Reload Conversarium — re-reads the local folder. This does not contact ChatGPT.

Row actions

  • Click a row — select it for export. Select all — the checkbox at the top. Double-click a row — export just that thread (local only; no ChatGPT request).
  • 📄J — copy this Conversarium thread's canonical JSON to the clipboard.
  • 📄M — render this Conversarium thread as markdown and copy it.

Search

Searches inside Conversarium threads. Try: hydration (fuzzy), code: (threads with code blocks), user: topic (your messages only), assistant: topic (replies only). Result cards show tag chips (after Digest) and an Open in ChatGPT ↗ deep link.

Where everything lives

Conversariumthreads/<Title> (<id>).json — the source of truth
Vaultchats/<Title> (<id>).md — markdown, never JSON
BrowserTiny caches only (settings, import checkpoint) — no thread data

Re-import is always possible while threads exist in your ChatGPT account — deleting the Conversarium is recoverable. Forgetting a folder never deletes the folder or any file in it.
